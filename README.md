Habit Formation App & Data

This repository contains the code and data for the smartphone-based experimental task described in Experimental habit formation using smartphone applications: challenges in inducing devaluation with extended training (Bar Or & Schonberg, 2025).

The project was designed to study human habit formation outside the laboratory through repeated, gamified button-press tasks delivered via a progressive web app.

App Code Usage

⚠️ Note: The original server infrastructure that hosted the app is no longer available. As such, the application cannot be deployed in its original form out-of-the-box.

However, the repository remains useful for:

1. Reviewing the implementation of the progressive web app (HTML/JS/CSS).

2. Reusing or adapting the experimental task logic for other projects.

3. Accessing and analyzing the raw data and code shared for reproducibility and further research
